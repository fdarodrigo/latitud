Create a Next.js 14 project with App Router, TypeScript, Tailwind CSS and shadcn/ui with the following specification:
Context: A real estate search product called "Latitud". The main feature is an interactive map displaying properties for rent or sale.
Stack: Next.js 14 (App Router), TypeScript, Tailwind CSS, shadcn/ui, @vis.gl/react-google-maps, zustand, @tanstack/react-query, lucide-react, embla-carousel-react.

Page /map: Layout split into a fixed left sidebar (380px wide) and the map occupying the remaining screen space.

Sidebar (src/domains/map/components/MapSidebar.tsx): Show the "Latitud" logo at the top. Below it, a toggle for Aluguel/Venda (Rent/Sale). Zustand store at src/domains/map/store/map.store.ts: state fields allListings, filteredListings, activeFilters, selectedListing | null.
useListings hook: Uses react-query to fetch mock data (simulate with Promise.resolve(mockData)). On success, populates the Zustand store.
Google Maps API key: Read from environment variable NEXT_PUBLIC_GOOGLE_MAPS_KEY. Load the places and geometry libraries in the loader config.
